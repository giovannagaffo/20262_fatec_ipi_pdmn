Para colocar a aplicação em funcionamento a partir de um clone do repositório, siga os passos abaixo:

Abra o terminal na pasta raiz do projeto e instale as dependências:
npm install
npm install primereact primeicons primeflex 
npm install @primeuix/themes
npm install axios

Preencher a chave da PRIMEUI e GEOAPIFY_KEY
Chave: PrimeUI (criar uma conta na https://primeui.store/ e pegar a licença)
